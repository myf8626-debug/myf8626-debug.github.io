# 政策溯源问答

**状态：可复现样例与接口已实现，真实模型尚未接入。**

输入问题、入学年级和查询日期，从人工结构化条款中筛选适用依据，处理冲突和无依据情形。

## 已实现
- 竞赛、奖学金、实习、毕业四类关键词检索；多个主题同时出现时要求拆分问题。
- 入学年级过滤、生效日期包含 / 失效日期不包含的区间判断。
- 精确引用适用条款，不自动改写；同一主题有不同 value 时保留冲突。
- 查看被排除条款及原因，导入结构化 JSON，导出查询记录。

## 一个可复现案例
2024 级在 2026-08-31 查询竞赛学分，引用旧条款 P1；查询日期改为 2026-09-01 后引用 P2。
2026 级同日查询则引用 P3。实习主题的 P5 / P6 同时适用但值不同，返回冲突而不任意挑选。

## 结果与限制
样例库有 8 条人工构造条款，完全不代表郑州轻工业大学或其他学校的真实政策。
当前是结构化字段与关键词检索，没有接入 LightRAG、图谱检索、向量索引、PDF 解析或语言模型。
页面的依据路径仅展示实际过滤步骤，不是知识图谱推理结果。没有人工审核的真实政策库，不能用于政策决策。

## 技术栈
Python 3.11+ 标准库、原生 HTML / CSS / JavaScript。无需 npm 构建、数据库服务或 API Key。
浏览器和 Python 分别实现同一确定性核验流程，并进行一致性检查。

## 启动
在解压后的项目根目录运行：

```powershell
python server.py --port 8312
```

打开 http://127.0.0.1:8312/ 。默认只监听本机，不作为公网后端部署。
也可只把 web/ 部署到静态网站；在线样例在浏览器本地计算，不会上传导入的资料。
跨项目导航链接面向作品集的 /labs/ 目录，单独运行时会自动指向在线作品集。

## API
- GET /api/health：确认样例模式与模型未连接。
- POST /api/ask：请求字段及样例见下。
- POST /api/model：明确返回 HTTP 501；不静默伪造模型结果。
- 完整字段说明见 API.md；没有鉴权、持久化用户资料或在线模型配置。

```json
{
  "query": "竞赛学分",
  "cohort": 2024,
  "as_of": "2026-11-09"
}
```

## 验证
```powershell
python evaluate.py
```

本次运行 20 项确定性回归检查，20 项通过；详细用例、样例哈希和执行时间在 web/evaluation.json。
这是已知预期的小样本逻辑检查，不是模型评测，不可换算成真实准确率或编造率下降。
