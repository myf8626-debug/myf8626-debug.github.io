# 岗位调研证据台

**状态：可复现样例与接口已实现，真实模型尚未接入。**

输入人工整理的来源与结论，检查引用是否能定位到原文，并保留相互冲突的信息。

## 已实现
- 核对 source_id、原文引文、Unicode 字符区间（左闭右开）。
- 对人工结构化 facts 字段做精确值核验；相同字段存在多个值时标记冲突。
- 区分可回溯、来源冲突、缺少依据、引文不匹配、字段不支持。
- 导入 JSON、筛选结果、导出带依据的记录。

## 一个可复现案例
样例 C1 引用 S1 的“远程”，但 S3 的同一字段为“上海”，所以显示来源冲突，不自动挑选更新日期的说法。
C6 引文文字真实存在，但起始位置错了一位，所以显示引文不匹配。
C7 引用了每周 5 天的原文，却声称 3 天，所以显示字段不支持。

## 结果与限制
7 条人工构造结论的预期分类：3 条可回溯、1 条冲突、1 条缺少依据、1 条引文不匹配、1 条字段不支持。
这里的“可回溯”不意味着现实事实已被证实。facts 是人工输入的结构化字段，并不是自动从网页抽取的事实。
尚未实现联网搜索、网页抓取、语义蕴含判定及模型驱动调研。不对真实岗位真实性作保证。

## 技术栈
Python 3.11+ 标准库、原生 HTML / CSS / JavaScript。无需 npm 构建、数据库服务或 API Key。
浏览器和 Python 分别实现同一确定性核验流程，并进行一致性检查。

## 启动
在解压后的项目根目录运行：

```powershell
python server.py --port 8311
```

打开 http://127.0.0.1:8311/ 。默认只监听本机，不作为公网后端部署。
也可只把 web/ 部署到静态网站；在线样例在浏览器本地计算，不会上传导入的资料。
跨项目导航链接面向作品集的 /labs/ 目录，单独运行时会自动指向在线作品集。

## API
- GET /api/health：确认样例模式与模型未连接。
- POST /api/analyze：请求字段及样例见下。
- POST /api/model：明确返回 HTTP 501；不静默伪造模型结果。
- 完整字段说明见 API.md；没有鉴权、持久化用户资料或在线模型配置。

```json
{
  "dataset": "可选：与 web/sample.json 同格式的对象"
}
```

## 验证
```powershell
python evaluate.py
```

本次运行 16 项确定性回归检查，16 项通过；详细用例、样例哈希和执行时间在 web/evaluation.json。
这是已知预期的小样本逻辑检查，不是模型评测，不可换算成真实准确率或编造率下降。
